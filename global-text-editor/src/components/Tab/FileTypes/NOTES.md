
# File Types

## Normal Type
This is the default type note. It supports

### Text
- headings, italic, bold, underline, 
- text color, highlight

### Styles
- page color

### Features
- list (bullet, number, todo)
- callout, quote
- code word, code block
- alignment
- image upload
- undo, redo
- link

## Markdown Type
Supports markdown type notes.
I think this can be renderered in two ways.
1. sheer markdown syntax view
2. preview

Users should be able to switch between two. That way, I also should provide "preview" button

## Page Type
This lay outs a page whether you can edit your text.
This can be used if you want "true" document feel. Also, you want to assort note elements in a more neat way.


## Diagram (draw.io kind)
This provides draw.io like page where you can create a diagram


## Canvas Type
This is infinite board canvas.
This will be exclusively supported only on tablet (ipad).

### Features
- printout PDF (this lays out all pages in PDF)
- lasso tool
- adding image
- insert text
- pen and erase

## PDF Type
This requies PDF file upload. Then, once it is uploaded, it will parse it and lay out PDF pages.
This is not so different from Canvas. You will have to think whether they actually need to be separate.

### Features
- lasso tool
- adding image
- insert text
- pen and erase
- pdf overview and page summary
