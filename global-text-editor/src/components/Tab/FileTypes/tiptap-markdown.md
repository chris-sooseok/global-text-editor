
# Tiptap markdown
> https://tiptap.dev/docs/editor/markdown

The markdown extension provides parse Markdown strings into Tiptap's JSON format and serialize eidtor content back to Markdown

The extension acts as a bridge between Markdown text and Tiptap's JSON document structure. 

> Markdown import or export  https://tiptap.dev/docs/conversion/import-export/markdown/editor-extensions
