# ESLint
## What is ESLint?
Linting is the automated process of checking source code for errors, bugs, and stylistic issues using a tool called linter.
Then, ESLint is an open-source `JS` linting utility developed in 2013. It is frequently used to find problematic patterns or code that doesn't adhere to certain style guidelines. ESLint is written using Node.js to provide a fast runtime environment and easy installation via npm. With **ESLint** you can impose the coding standard using a certain set of standlaone rules. You can turn those rules on and offm and these rules are completely pluggable.

## Why use ESLint?
`JS`, being a dynamic and loosely-typed language, is especially prone to developer error. ESLint lets you put guidelines over coding standard and helps you to minimize those errors. The main reason for imposing those guide is because every developer has her style of writing (like naming conventions/tabs/single or double quotes for a string). And, with different styling techniques, your codebase may look weird, more error-prone and vulnerable. Especially when you’re dealing with Javascript this could cause pitfalls you’d never want to deal with.
